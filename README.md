A 4,091-byte chess engine in Python: a 0x88 board, negamax alpha-beta with iterative deepening to a fixed 100,000-node budget, quiescence search, transposition table, killer moves and piece-square evaluation. Practice Elo 1602 (mean over the kit's 3 practice trials) against the house gauntlet — above the sunfish 4K baseline.

## Run it

```sh
python3 main.py
```
